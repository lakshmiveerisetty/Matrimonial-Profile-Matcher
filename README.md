# Matrimonial Profile Matcher

## Description
A Java console application that matches matrimonial profiles based on user preferences.

## Technologies Used
- Java
- Eclipse IDE
- Git
- GitHub

## Features
- User Registration
- Age Validation
- Salary Matching
- Profile Matching Result
- Console Menu
- Profile Matching
- Search Profiles
- Simple Console-Based Interface

## How to Run
1. Clone the repository
2. Open the project in Eclipse IDE
3. Run MatrimonialProfileMatcher.java
4. Follow the on-screen instructions
